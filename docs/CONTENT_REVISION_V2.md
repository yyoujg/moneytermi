# 용어·예시·시각자료 2차 교정

## 반영 결과

- 운영 용어 1,233개 중 **242개 용어의 306개 필드** 교정.
- 핵심 뜻 19개, 상세 뜻 27개, 학습 예시 210개, 빈칸용 예문 10개, 시각자료 필드 40개.
- 뜻만 인용·반복하던 예시 194개를 모두 정리했다. 별도 작성한 188개 예시는 두 묶음의 독립 검토를 거쳤다.
- 비퀴즈 시각자료 **766개 전수 대조**, 실제 변경은 48개 카드. 기존 퀴즈는 2개를 보완하고 총 **401개**를 유지했다.
- 운영 재조회: 대상 242/242개 일치, 비대상 991개 동일, 코스 78개·코스 연결 1,234행 동일.
- 단어명·아이디·힌트·관련 단어·출처 분류·난이도 및 개인 학습 기록·재화는 변경하지 않았다.

## 주요 교정

만기수익률과 실현수익률의 조건, 현금성자산의 취득 시 만기, 이익잉여금과 보유 현금, 집단대출의 차주 심사, 온라인투자연계금융법 시행 시점, 임차권등기 신청과 실제 등기완료를 구분했다. 특별인출권의 준비자산 성격·최초 금 등가액·특별배분 조건, 거미집 모형의 가정, 계약곡선의 파레토 기준과 시각자료 잔존 문구도 보완했다.

통계 연결은 등록 차트 21개·고유 시계열 15개를 공개 조회했다. 모두 유효 자료를 받았고, 공식 항목·단위와 14개 최신값을 대조했다. 통화량의 원계열·평잔과 코스피의 월별 종가 표기를 실제 연결 자료에 맞췄다.

## 근거와 복구

- 상세 원본·수정값·이유·근거 주소: `supabase/content/meaning-quiz-revision-v2.json`
- 적용: `supabase/content/apply-meaning-quiz-revision-v2.sql`
- 복구: `supabase/content/rollback-meaning-quiz-revision-v2.sql`
- 운영 재조회 기록: `docs/content-revision-v2-verification.json`

적용·복구는 트랜잭션 안에서 단어 식별값, 검토 문맥, 변경 필드의 현재값을 먼저 대조한다. 다르면 전체 중단하며 기존 편집을 덮어쓰지 않는다. 모든 대상을 잠그고 확인한 뒤 쓰기와 결과 검증을 수행한다. 운영에서 먼저 전부 취소하는 검사를 통과하고 원본 1,233개와 코스 전체의 동일성을 재조회한 후 실제 반영했다. 복구는 1차 교정까지 취소하는 것이 아니라 **이번 2차 변경 직전 값**으로 되돌린다.

## 검증 한계

- 외환건전성부담금·예대율의 현행 세부 요율·한시 조치 전체를 확정하지 않았다. 미확인 현행 수치 단정은 제거하거나 확인된 과거 시점을 명시했다.
- 통화량 원문 최신값 1개는 직접 대조하지 못했다. 항목의 원계열·평잔 및 환산 단위는 확인했다.
- 균제상태는 근거를 확보한 고정 기술수준 모형으로 범위를 제한했고, 미확인 확장 설명·기본소비의 미확인 동의어는 추가하지 않았다.
- 통계의 미래 개정·수록 지연이나 이후 규정 변경까지 보증하지 않는다.
- 기존에 열린 앱의 메모리 내용은 즉시 교체하지 않으며 콘텐츠 재로딩 시 새 내용을 사용한다.
