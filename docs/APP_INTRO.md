# 머니터미 - 앱 소개

## 개요

**머니터미**는 토스 앱 내 미니앱으로, 경제/금융 용어를 게임처럼 재미있게 학습할 수 있는 학습 플랫폼입니다.

복잡한 경제 용어를 카드 학습, 퀴즈, 리그 경쟁 등 다양한 방식으로 학습하여 자연스럽게 금융 이해도를 높일 수 있도록 설계되었습니다.

---

## 주요 기능

### 1. 학습 현황 확인하기 (홈)

- 오늘의 학습 현황 요약 (총 포인트, 연속 출석, 학습 단어 수)
- 신규 유저(학습 이력 0)는 빈 통계 대신 "단어 1개만 배워볼까요?" 단일 CTA로 첫 학습 유도
- 앱 진입 시 오늘 출석 자동 체크 (출석 미션 자동 완료)
- 주간 출석 막대 차트로 학습 흐름 시각화
- 데일리 미션 (출석 체크, 퀴즈 정답 맞히기) 및 포인트 보상 수령
- 추천 코스 바로가기

### 2. 코스별 단어 학습하기 (코스)

- 경제 / 금융 카테고리별 코스 구성
- 총 22개 코스, 233개 경제·금융 용어 (코스별 단어 묶음)
- 학습 권장 순서(sort_order)로 코스 정렬
- 코스 학습 진행률 (%) 실시간 표시
- 단어 검색 기능

### 3. 단어 카드로 학습하기 (단어 카드)

- 단어 뜻 / 상세 설명 / 뉴스 예시 / 연관 단어 슬라이드 방식으로 제공
- 네이버 뉴스 API 연동으로 해당 단어 관련 실시간 뉴스 표시
- 연관 단어 클릭으로 즉시 이동
- "알아요 / 모르겠어요" 체크로 학습 상태 저장
- "실천하기"로 해당 개념과 연결된 실천 항목을 내 목록에 담기

### 4. 퀴즈 풀기 (퀴즈)

- 학습한 단어 기반 4지선다 퀴즈
- 콤보 시스템: 연속 정답 시 포인트 보너스
  - 기본 10P -> 3콤보 15P -> 5콤보 20P
- 퀴즈 종료 후 정확도 / 획득 포인트 / 예상 순위 변동 표시

### 5. 단어 복습하기 (복습)

- "오늘 복습할 단어"만 출제하는 간격반복(SM-2 lite) 복습 (첫 학습 단어는 다음날부터 복습 대상)
- 정답/오답·초성 힌트 사용 신호로 다음 복습일 자동 산정 (오답은 즉시 재출현, 정답은 복습 간격이 점점 늘어남)
- 홈의 "오늘 복습할 단어 N개" 카드로 진입(하루 최대 10개), 큐를 다 풀거나 복습할 단어가 없으면 완료·빈 상태 표시
- 주관식 직접 입력 + 초성 힌트 제공 (예: ㄱㄱㄷ)
- 초성 힌트 사용 시 5P, 미사용 시 10P + 콤보 보너스 (2연속 이상)
- 하단 탭의 "퀴즈"가 이 복습 화면으로 연결됨

### 6. 실천하기 (실천)

- 단어 카드에서 담은 실천 항목과 직접 추가한 항목을 체크리스트로 관리
- 미완료 / 완료 분리, 완료 항목은 취소선 표시
- 각 항목에 연결된 개념(용어) 라벨 표시
- 포인트와 무관한 행동 기록 (체크만으로 진행)

### 7. 리그에서 순위 경쟁하기 (리그)

- 포인트 기반 5단계 경쟁 티어 시스템
  - 알개미 -> 뽀시래기 -> 왕개미 -> 전투개미 -> 슈퍼개미
- 본인 포함 최대 50명 실시간 리더보드
- 상위 5명 승급 / 하위 5명 강등, 매주 월요일 00:00 초기화
- 나보다 위/아래 사용자와의 포인트 차이 표시
- 이모지 아바타로 시각적 차별화
- 리그 화면을 토스 공유 시트로 친구에게 공유

### 8. 내 정보 관리하기 (마이페이지)

- 닉네임 / 이모지 아바타 커스텀
- 월별 출석 캘린더 확인 및 출석하기
- 테마 설정 (시스템 기본 / 라이트 / 다크)
- 사운드 / 진동 설정
- 학습 알림 동의 (앱인토스 스마트 발송 기능성 메시지 수신 동의)
- 앱 사용법 안내
- 로그아웃 (가입 계정)

## 사용자 플로우

### 첫 방문
1. 기본 닉네임('예비슈퍼개미') + 기본 이모지('🍊')로 게스트 프로필 자동 생성
2. 이메일 없이 바로 학습 시작 가능

### 일일 학습 루틴
1. 홈에서 오늘의 미션 / 오늘 복습할 단어 확인
2. 코스 선택 -> 단어 카드 학습 (관심 개념은 "실천하기"로 담기)
3. 퀴즈 / 복습으로 학습 마무리
4. 실천 항목 체크
5. 미션 보상 수령 및 리그 순위 확인

## 데이터 구조

전체 스키마 / 타입 / 동기화 흐름은 [DATA_STRUCTURE.md](./DATA_STRUCTURE.md) 참고.

### 핵심 테이블

- **profiles** - 사용자 프로필 (닉네임, 이모지, 포인트, 티어, 게스트 여부)
- **words** - 경제 용어 (단어, 뜻, 상세설명, 뉴스예시, 힌트, 연관 단어)
- **courses** - 코스 목록 (카테고리, 레벨, 제목, 표시 순서 sort_order)
- **course_words** - 코스-단어 매핑 (순서 포함)
- **word_progress** - 사용자별 단어 학습 상태 (알아요/모르겠어요) + 간격반복 일정 (ease / interval / due_date)
- **actions** - 공개 실천 항목 템플릿 (개념 연결)
- **user_actions** - 사용자별 실천 체크리스트 (담은/직접 추가 항목, 완료 상태)
- **daily_missions** - 일일 미션 진행 상태 (날짜별 초기화)
- **attendance** - 출석 기록 (날짜별)

- 경제 용어는 어렵지만 게임처럼 배우고 싶은 MZ 세대
- 주식 / 재테크에 관심 있는 20-40대

## 설계 원칙

- **게임화 (Gamification):** 포인트, 콤보, 리그, 미션으로 학습 동기 유지
- **낮은 진입장벽:** 이메일 없이 게스트로 즉시 시작, 이후 계정 연동 유도
- **짧은 세션 최적화:** 하루 5-10분 내로 완료 가능한 단위로 구성
- **오프라인 지원:** Supabase 연결 실패 시에도 로컬 스토리지로 학습 유지
- **토스 네이티브 경험:** AIT 스토리지, TDS 컴포넌트로 토스 앱과 일관된 UX
