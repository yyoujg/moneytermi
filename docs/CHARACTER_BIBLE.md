# 머니터미 캐릭터 바이블

2026-11-03 v5 기준. 검수에서 "범용 3D 클레이 마스코트, 사용자 아바타도 수달, 리그 2위만 다른 그림체"가 반복 지적돼 만든 기준 문서다. 3D 수달은 v5 낙서 수달로 교체했고, 사용자 아바타는 수달과 분리했다(7절).

## 1. 성격

- **이름**: 달리. 수달의 "달"에서 왔다. 말풍선의 화자로 쓴다(홈 말풍선, 첫 화면 "달리와 먼저 한 문제 풀어 볼까요?"). 2026-11-04 정함. NH농협은행 올원프렌즈에 같은 이름의 강아지 캐릭터가 있다는 것을 알고 정했다. 상표 등록 여부는 확인하지 않았다.
- **형용사 3개**: 꼼꼼하다, 차분하다, 다정하다.
- **역할**: 앱의 화자. 사용자와 같은 학습자가 아니라, 옆에서 다음 할 일을 알려주는 길잡이다.
- **하지 않는 것**: 과장된 칭찬("천재예요!"), 재촉·압박("오늘 안 하면 끊겨요"), 돈 자랑·투자 권유, 사용자 흉내(아바타 역할).

## 2. 형태

- **그림체**: 손으로 그린 듯한 낙서 선. 선 굵기가 조금씩 흔들리는 것이 특징이고, 이를 매끈하게 다듬지 않는다.
- **실루엣**: 둥근 머리 + 머리 옆에 낮게 붙은 작은 귀 + 길쭉하게 서 있는 몸 + 몸 옆으로 뻗은 꼬리. 검정 실루엣만으로 수달로 읽혀야 한다.
- **얼굴**: 작은 점 눈, 검은 코, 크림색 주둥이. 큰 반짝이는 눈·볼터치는 쓰지 않는다.
- **배**: 목에서 아래까지 크림색 긴 배.
- **소품·옷**: 없음. 돌·스카프·액세서리를 두지 않는다.

## 3. 색

3색만 쓴다. 그라데이션·광택·그림자 없음.

| 역할                  | 값        |
| --------------------- | --------- |
| 선·눈·코·실루엣       | `#1F1A17` |
| 몸                    | `#8C7C6D` |
| 배·주둥이(크림)       | `#F8EFDE` |

- 색은 SVG 안에 고정돼 있고 화면 토큰을 따르지 않는다. 앱은 라이트 모드로 고정이라 흰·옅은 회색 바탕에서만 쓴다.
- **다크 모드**: 앱인토스 미니앱이 라이트 모드만 지원해 쓰지 않는다. 흰 외곽선을 깐 `-dark` 파일은 2026-11-04에 지웠고, 필요하면 git 이력이나 `trace.py`로 다시 만든다.

## 4. 포즈 5종

파일은 `public/otter/v5/otter-<포즈>[-small].svg`, viewBox 120x120 정사각형.

| 포즈           | 파일명    | 모습                       | 쓰는 곳                        |
| -------------- | --------- | -------------------------- | ------------------------------ |
| 기본           | `idle`    | 두 손을 모으고 서 있음     | 온보딩 첫 화면                 |
| 만세           | `cheer`   | 두 팔을 들고 웃음          | 학습 완료, 퀘스트 미션 모두 완료 |
| 설명           | `explain` | 한 손가락을 들고 웃음      | 아직 없음(예전 홈 전신)        |
| 놀람           | `shock`   | 두 손으로 얼굴을 감싸고 입을 벌림, 머리 위 효과선 | 아직 없음(연속 학습 끊김·에너지 부족 후보) |
| 좌절           | `defeat`  | 엎드려 누움, 머리 위 소용돌이 | 아직 없음(불러오기·저장 실패 후보) |

- **변형 2종**
  - 일반본(`otter-<포즈>.svg`): 64px 이상.
  - 단순화본(`-small`): 면을 깎아 선을 굵게 만든 것. **40px 이하에서는 단순화본을 쓴다.**

## 6. 포즈 추가 방법

1. 기준 이미지(`docs/character/ref.png`)를 만든 것과 같은 프롬프트로 새 포즈 이미지를 생성한다.
2. **생성할 때마다 얼굴이 조금씩 달라지므로 `ref.png`와 나란히 놓고 비교해 확인한다.** 귀 위치, 눈·코 크기, 주둥이 모양, 배 범위가 같아야 한다.
3. `docs/character/trace.py`로 벡터화한다. 색 영역(배경·몸·크림·선)을 나눠 potrace로 추적하고, 일반본·단순화본·다크본 3종을 만든다(다크본은 쓰지 않으니 넣지 않는다). 스크립트는 한 이미지에 포즈 5개가 가로로 놓여 있다고 가정하므로(`NAMES`, `len(big) == 5`) 포즈 수가 다르면 맞게 고친다.
4. `docs/character/preview.py`로 확인 시트(`preview.html`)를 만들어 120px·32px·실루엣·다크 바탕에서 본다. 마지막 확인 화면은 `docs/character/preview.png`.
5. 결과 SVG를 `public/otter/v5/`에 넣는다.

## 7. 사용자 아바타 분리 (2026-11-03 적용)

마스코트는 앱의 화자이고, 사용자는 마스코트가 아니다. 아바타는 별도 체계로 만든다.

- **형태**: 원 안에 닉네임 첫 글자 1자. 그림 없음.
- **색**: 배경은 옅은 중립·라임 틴트 중 하나(`--color-surface`, `--color-accent-soft` 등 기존 토큰), 글자는 `--color-ink-2`. 닉네임으로 색을 고정해 같은 사람은 늘 같은 색이다. 새 색을 만들지 않는다.
- **선택**: 이모지 선택(`EmojiPickerSheet`)과 아바타 편집 버튼은 없앴다. 색은 사용자가 바꾸지 않는다.
- **서버 데이터**: `profiles.emoji` 값은 그대로 두고 화면에서만 쓰지 않는다(되돌리기 쉽게).

## 8. Do / Don't

- **Do**: 3색·낙서 선·비율 그대로, 포즈만 바꾸기. 감정 지점에서만 등장. 40px 이하는 단순화본.
- **Don't**: 늘이기·찌그러뜨리기, 색 바꾸기, 그라데이션·광택·그림자·3D 효과 추가, 큰 눈·볼터치 추가, 소품·옷 추가, 선을 매끈하게 다시 그리기, 사용자 아바타로 쓰기, 다른 브랜드의 수달·해달 캐릭터와 닮게 그리기.

## 9. 남은 것

- 놀람·좌절 포즈를 쓸 화면(연속 학습 끊김, 에너지 부족, 불러오기 실패)은 아직 정하지 않았다.
- 다른 브랜드 수달 캐릭터와의 유사도 비교는 아직 하지 않았다.
