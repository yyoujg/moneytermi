# 사용자 흐름 개선

기준: `ca774dc` 이후 작업본. 운영 데이터와 보상 규칙을 바꾸지 않는 화면·복구 흐름 개선이다.

## 반영 내용

### 관련 용어 미리보기
- 같은 코스·다른 코스의 관련 용어를 읽기 전용 대화상자로 연다.
- 원래 레슨의 위치, 용어 배열, 코스·노드 식별자, 이어갈 용어와 복귀 경로를 그대로 유지한다.
- 미리보기 안에서 다른 용어 탐색, 이전 미리보기, 상세 설명·뉴스 확인을 지원한다.
- 닫기·취소·배경 클릭 후 원래 학습으로 복귀한다. 기기 뒤로가기도 미리보기를 먼저 닫는다.
- 제목 초점, 키보드 초점 순환과 닫은 뒤 초점 복원을 보완했다. 미리보기는 진도·보상 요청을 하지 않는다.

### 프로필 저장 결과
- 닉네임은 서버의 실제 갱신 행 확인 후 인증 상태를 갱신한다. 기기 캐시 오류를 서버 변경 실패로 안내하지 않는다.
- 저장 프로필로 재진입할 때 캐시를 즉시 보여준 뒤 인증된 서버 닉네임을 비동기 재조회한다. 늦은 응답은 수동 변경 성공이나 다른 프로필을 덮지 않는다.
- 프로필 캐릭터는 실제 서버 갱신 확인 뒤에만 화면에 반영한다. 저장 중 중복 선택을 막고 실패하면 선택창에서 다시 시도할 수 있다.
- 기존 캐릭터 저장값과 표시 매핑을 자동 변경하지 않는다.

### 구매·미션 상태
- 부스트의 성공·이미 적용·명시적 잔액 부족·요청 진행 중·결과 미확인을 구분한다.
- 통신 오류나 응답 확인 실패를 잔액 부족 또는 미차감으로 단정하지 않는다. 구매 중 연속 클릭을 막는다.
- 자동 미션 보상 적립 중에는 ‘적립 중’을 표시한다. 같은 요청의 진행 중 반환을 수동 수령 실패나 추가 성공으로 해석하지 않는다.
- 보상 요청 예외 후 잠금을 해제해 다시 수령할 수 있다.

### 결과·다음 학습 안내
- 이해 확인의 첫 풀이 결과와 각 재도전 결과를 분리한다. 재도전 회차를 문제·결과 화면에 표시한다.
- 결과 보기 연타로 같은 회차를 중복 기록하지 않는다.
- 완료 시 ‘다음 학습 선택하기’로 원래 주제에 복귀한다. 다음 레슨을 자동 시작하거나 에너지를 미리 차감하지 않는다.
- 코스 안내문은 분류, 제목, 세부 용어 순으로 선택해 일부 용어가 전체 코스 요약을 덮지 않도록 했다.

## 보존 범위

- 운영 데이터베이스·서버 질의문·코스 연결·학습 기록은 이번 작업에서 수정하지 않았다.
- 재화 잔고·가격·에너지 소모 조건·보상 계산은 기존 서버 및 기존 규칙을 유지한다.
- 인증 및 닉네임 길이·중복·기본 닉네임 검증 조건과 저장 형식을 유지한다.
- 기존 출시본과 검수 요청을 취소하거나 교체하지 않는다. 로컬 빌드와 업로드·검수·출시는 별도 상태다.

## 검증 범위

- 실제 상태 공급 컴포넌트와 화면 컴포넌트를 사용한 회귀 검사에서 데이터베이스·브리지·기기 저장소만 대역 처리하고 외부 통신을 차단한다.
- 브라우저 검증은 운영 계정과 분리된 모의 환경이다. 기기 뒤로가기 모의는 실제 앱에서 사용하는 대화상자 닫기 함수를 사용한다.
- 실제 아이폰 토스 앱의 네이티브 뒤로가기, 화면 읽기 기능과 실기기 저장소 장애는 별도 확인 대상이다.
- 최종 자동 검사·빌드 및 브라우저 확인 결과는 작업 완료 보고에 기록한다.
