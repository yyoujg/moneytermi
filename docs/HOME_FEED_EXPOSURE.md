# 앱인토스 전체탭(홈피드) 노출 진단 및 재노출 전략

> 작성 2026-07-15. moneytermi의 전체탭 노출 중단 원인 진단과 재노출 레버 정리.
> 공식 문서에 노출 알고리즘 세부는 비공개라, [확인된 사실]과 [추론]을 구분해 기록한다.
> 확정이 필요한 항목은 채널톡(콘솔 우하단)이 유일한 공식 경로다.

---

## 1. 배경 / 문제

- 5월 초기: 전체탭(홈피드) 스파이크 유입(신규 130명 수준, 40대+ 42%).
- 6월 중순 이후: 전체탭 신규 유입이 30일간 약 1명 수준으로 사실상 중단.
- 반전 데이터: **전체탭 유입 코호트의 리텐션이 우량** — D1 43%, D30 29%(타 경로 대비 뚜렷이 높음).
- 잔존 유저 구성은 30대 초반 62%로 이동(5월 40대+ 42% 대비).

> 앞선 "D7=0" 판정은 경로 혼합/스파이크 오염 수치였고, 경로를 분리하니 전체탭은 우량 자산.
> 즉 "리텐션이 나빠서 노출이 끊겼다"는 가설은 데이터로 반증된다.

---

## 2. 홈피드 노출 선정 기준 (확인된 사실)

- **파트너 직접 통제 불가.** 노출 대상/위치는 토스 내부 기준으로 선정. 선정 알고리즘 비공개.
- **노출 채널(유입 경로 7종):** 전체탭 · 검색 · 혜택탭 · 푸시/알림 · 게임홈 · 연락처 모듈 · 기타.
- **유일한 파트너 레버 = 핵심 지표(전환/활성 지표).**
  - 전환 지표 최대 3개 등록, 그중 1개를 핵심 지표로 지정.
  - 핵심 지표는 노출 최적화 + 관심 사용자 추천의 기준.
  - 활성 지표 템플릿: "n일 후 재방문 유저", "n분 이상 체류", "하루 n회 이상 방문".
  - 공식 문구: "토스가 활성 유저와 비슷한 유저를 찾아 노출하고 추천." "핵심 지표를 잘 설정한 앱일수록 더 적합한 유저에게 노출될 기회가 커져요."
  - 즉 **노출 = 핵심 지표 달성 유저와 닮은 유저(lookalike) 타겟팅.**
- **게이트:** 노출 모수는 만 19세 -> 틴즈(14세+) 확대. 혐오/차별 등 소재 점검 대상이면 노출 제한/조치.

## 3. 진단: 리텐션이 좋은데 왜 축소됐나 (추론)

공식 미공개라 확정 아님. 가장 개연성 높은 구조적 설명:

1. **5월 스파이크 = 신규 출시 초기 디스커버리 부스트.** 시간제한적이며 리텐션과 무관하게 소진.
   부스트 종료 후 지속 노출은 알고리즘의 능동 타겟팅에 의존.
2. **활성 유저 절대 규모 부족.** 리텐션 %는 좋아도 seed 코호트가 작으면(130명 수준) lookalike
   확장 근거가 약함. 좋은 % != 노출 우선순위.
3. **핵심 지표 미설정.** 노출/추천 최적화의 기준 신호가 없어 알고리즘이 확장 대상을 못 좁힘.
   (= 파트너가 당길 수 있는 레버)
4. **전체탭 슬롯 한정 + 신규 앱 로테이션 경쟁.**

-> "리텐션 부재"가 아니라 **초기 부스트 소진 + 규모/핵심지표 신호 부재**일 개연성.
   리텐션 자산이 살아있으므로 신호와 규모만 확보하면 재노출 여지가 크다.

## 4. 질문별 정리 (Q&A)

### Q1. 전체탭 노출 중단 사유(정책/소재) 확인 가능한가
- 정책/소재 이슈면 흔적이 남는다: 검수 반려, 콘솔 알림/이메일, 소재 점검 조치 통보.
  -> 먼저 콘솔 검수 이력/공지/알림 확인. 조치 이력 없으면 정책 사유 가능성 낮음.
- 단 노출 중단은 정책 위반 아니어도 발생(부스트 소진/로테이션). **확정은 채널톡뿐.**

### Q2. 리텐션 좋은데 축소된 이유
- 3장 진단 참조: 초기 부스트 소진 + 활성 유저 절대 규모/핵심지표 신호 부재일 개연성.
- 확정은 채널톡.

### Q3. 핵심 지표 '첫 학습 카드 완료' 등록 -> 전체탭 반영? 변경 시 초기화?
- **반영은 됨** (핵심 지표는 노출/추천 최적화의 기준). 단 재노출 보장 스위치가 아니라
  타겟팅 적격성/최적화 근거를 제공하는 것.
- **지표 선택 주의:** '첫 학습 카드 완료'는 전환(activation) 지표. 노출 로직은 "활성 유저와
  닮은 유저 찾기"라, 강점인 재방문 리텐션(D1 43%)을 직접 쓰려면 **재방문 계열 활성 지표
  ("1일 후 재방문 유저")가 더 정합.**
  - 권장: 핵심 지표 = "n일 후 재방문 유저", 첫 학습 카드 완료는 보조 전환 지표(3개 중 하나)로.
  - activation을 핵심으로 걸면 "첫 학습까지 갈 신규"를 찾아줘 활성화엔 유리(트레이드오프).
- **초기화:** 공식 리셋 규정 없음. 문구는 "변경한 지표는 다음 날부터 적용", "신중히 설정"뿐.
  현재는 노출 중단으로 최적화 누적이 거의 없는 상태 = 변경 비용이 사실상 0인 시점(지금이 최적).

### Q4. 40대+ 42% -> 30대 초반 62%. 핵심 지표로 타겟 연령 조정되나
- **구조적으로 Yes(간접).** 노출은 핵심 지표 달성 유저와 닮은 유저 lookalike라, 타겟 연령은
  파트너가 지정하는 게 아니라 **핵심 지표 달성 유저 구성에서 emergent하게 도출.**
  잔존 활성이 30대에 몰리면 lookalike도 30대로 드리프트.
- 함의: 5월 40대+는 초기 부스트의 광범위 노출(리텐션 필터 전) 결과. 재개 시 30대 중심으로
  좁혀질 수 있음. 40대+를 원하면 (a) 40대가 핵심 지표를 달성하도록 제품/콘텐츠 정합,
  또는 (b) 세그먼트/프로모션으로 별도 유입. 핵심 지표가 연령을 직접 지정하진 않음.
- 연령이 명시적 파라미터인지 순수 emergent인지는 채널톡 확인 권장.

## 5. 재노출을 위해 개선할 지표 (우선순위)

| # | 지표 | 현재 | 목표 | 레버 | 상태 |
|---|---|---|---|---|---|
| 1 | 콘솔 핵심 지표 = "1일 후 재방문 유저" 등록 | 미설정 | 설정 | 콘솔 전환지표 -> 핵심지표 | 직접(ops), 최우선 |
| 2 | 활성화율 (`activation_first_card`/신규) | 홈 46% 이탈 | 첫 카드 완료율 상승 | 신규 단어1개 CTA, 홈 통계 숨김 | 코드 반영 완료 |
| 3 | D1 신규 리텐션(경로 무관) | 오염수치 | 전체탭 수준(43%)로 수렴 | 자동출석 + SRS due=내일 + 푸시 | 코드 반영 완료 |
| 4 | 푸시 동의율 + 실제 발송 | 모수 상한 27% | 동의율 상승 + 발송 가동 | 동의카드 첫카드로 이동 / 캠페인 활성 | 코드 완료 / ops 필요 |
| 5 | D7 신규 리텐션 | 게이트 7% | 7%+ | 위 결과 지표 | 후행 |

> 논리: 토스 알고리즘의 직접 입력은 "재방문 활성 유저". #1(핵심 지표 등록)이 코드보다 먼저.
> 전체탭 코호트가 이미 D1 43%이므로, 재방문 계열 핵심 지표는 그 강점을 알고리즘에 그대로 전달.

## 6. Ops 액션 (코드 아님, 직접 수행)

1. **콘솔 핵심 지표 등록** — "1일 후 재방문 유저"(재방문 계열). 첫 학습 카드 완료는 보조 지표로.
2. **콘솔 검수/공지/알림 이력 확인** — 소재/정책 조치 여부 점검.
3. **푸시 캠페인 가동 확인** — `moneytermi-DAILY_TERM_PUSH2` 스마트 메시지 캠페인이 실제 발송
   중인지. 동의를 받아도 캠페인이 안 돌면 D1 트리거가 죽는다.
4. **SRS 백필 SQL 실행** — `supabase/migration_srs_backfill.sql` (안 하면 복습 카드 즉시 과잉).
5. **채널톡 문의** — 아래 초안 발송.
