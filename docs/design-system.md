# 머니터미 디자인 시스템

## 시각 방향

머니터미의 이름과 제품 정체성은 그대로 유지한다. 부드러운 형태·파스텔 색·평면 UI의 일반적인 분위기만 참고하고 토끼 캐릭터나 특정 서비스의 공식 색상·고유 요소는 복제하지 않는다. 새로 제작한 독자 수달을 중심으로, 읽기 쉽고 차분한 금융 학습 화면을 만든다. 2026년 디자인 확정이나 특정 서비스의 공식 디자인이라고 표현하지 않는다.

현재 그림 자산은 2.5D의 매트한 평면 파스텔 일러스트다. 약한 깊이 표현은 가능하지만 사진 같은 털, 금속성, 유리광택, 강한 입체 버튼 표현은 쓰지 않는다. 모든 표면과 버튼은 그림자 없이 평평하게 표현한다. 캐릭터는 안내·완료·보상·빈 화면 등 적절한 장면에만 등장하고 학습 본문을 장식하지 않는다.

기존 그림을 보존한다는 이전 원칙은 이번에 사용자가 요청한 새 그림 제작·교체 대상에는 적용하지 않는다. 해당 캐릭터·역할 아이콘 자산은 교체되었으며, 기존 v2 및 원본 파일은 남아 있다. 보존 대상인 기존 데이터 그래프, 리그 등급, 금·은·동 표시 등은 별도 요청 없이 바꾸지 않는다.

## 색상·형태 토큰

`src/styles/tokens.css`가 색상·형태·행동 크기의 단일 원본이다. 화면별 고정 팔레트를 새로 만들지 말고 역할 토큰을 사용한다. `src/index.css`는 공통 역할과 그림자 없음 규칙을 적용한다.

| 역할 | 라이트 값 | 사용 |
|---|---|---|
| 캔버스 | `#f4f4f6` | 페이지 바탕 |
| 카드 | `#ffffff` | 주요 콘텐츠 표면 |
| 보조 표면 | `#f3f3f5` | 중성 보조 영역 |
| 제목 글자 | `#202124` | 제목·주요 수치 |
| 본문 글자 | `#45484f` | 본문·보조 행동 글자 |
| 보조 글자 | `#60646c` | 보조 설명 |
| 주행동 | `#3d3e44` | 주요 행동, 흰 글자 |
| 선택 강조 | `#8ecaa9` | 선택·강조 요소 |
| 브랜드 장식 | `#287a58` | 작은 선·장식 |
| 진행 | `#c27915` | 일반 진행 표시 |
| 보상 글자 | `#a45a00` | 보상 정보 |

일반 화면은 연회색 캔버스·흰 카드·차콜 주행동·민트 선택 강조·주황 계열 진행/보상 역할을 따른다. 이 값은 머니터미의 현재 코드 토큰이며 다른 서비스의 공식 색상이라는 뜻이 아니다. 다크 모드는 별도 어두운 표면과 밝은 글자·강조값을 토큰에서 사용한다. 화면마다 라이트 색상을 다크에 그대로 재사용하지 않는다. 정답·오답 등 의미색은 해당 상태 전달에만 한정한다.

카드 반경 `24px`, 버튼 `18px`, 칩 `14px`, 안쪽 영역 `16px`이다. 모든 그림자 토큰은 `none`이다. 주행동·보조 채움 버튼 글자는 흰색을 유지하고, soft 보조 버튼은 밝은 바탕에 짙은 글자를 쓴다. 버튼 기본 높이 `52px`, 큰 버튼 `56px`, 최소 터치 영역 `44px`; 공통 행동 글자는 `17px`, 보조는 `16px`, 굵기 `600`이다. 화면별 소형 조작은 아래 역할 규격을 따른다.

## 수달 및 그림 자산

새 수달과 역할 일러스트는 `public/otter/v3/`에 둔다. 핵심 그림 자산은 47개다: 캐릭터 4종(512px), 아바타 4종(256px), 정답/오답 피드백 2종(512px), 조개·물고기 2종(256px), 역할 아이콘 그림 20종(256px), 등급 5종(512px), 배지 10종(512px). 이와 별도로 배지 획득 제목 그림 1종이 있어 사용 PNG는 48개다. 기존 v2와 원본 자산은 남아 있으며 새 사용 경로는 v3로 변경되었다.

역할 그림 20종·조개/물고기 2종·배지 획득 제목 1종, 총 23종은 사용자 참고 이미지에 맞춰 연한 파스텔 원형 바탕과 단순한 사물 그림으로 통일한다. 두꺼운 윤곽선·금속 광택·그림자·복잡한 음영은 쓰지 않고 2개 톤의 작은 면으로만 깊이를 표현한다. 색상은 분홍·파랑·라벤더·크림·민트 배경을 사물 의미에 따라 구분한다. 편집 가능한 SVG 원본은 `public/otter/v3/icon-sources/`, 기존 연결용 PNG는 각 icons/items/celebrations 경로에 둔다. 수달 포즈·프로필 저장값·등급·수집 배지는 이번 아이콘 정리에서 변경하지 않는다.

`src/lib/otter.ts`는 수달 포즈와 호환 연결을 관리한다. `src/components/ui/OtterIcons.tsx`는 기존 아이콘 export 이름 43개를 유지한다. 기능 역할 그림은 20종이며 별칭으로 같은 이미지가 중복될 수 있다. 작은 조작 아이콘은 별도 SVG 21개로 `currentColor`를 따르며, 이미지 export는 별칭 포함 22개다. 조작 아이콘은 버튼 글자색을 따르고 역할 그림을 조작용 선 아이콘으로 바꾸지 않는다.

## 홈 화면

미션 제목·진행 요약은 미션 목록 바깥에 둔다. 각 미션은 의미에 맞는 역할 아이콘(28px)을 사용한다. 미션의 ‘받기’와 ‘완료’ 상태 표시는 너비 64px, 높이 44px, 글자 14px, 굵기 600으로 맞춘다. 받기는 실제 수령 행동, 완료는 누를 수 없는 완료 표시이며 기존 보상 수령 조건과 상태 로직을 바꾸지 않는다.

## 학습 코스 화면

코스 홈은 상단의 추천 학습 안내와 개별 주제 카드 목록으로 구성한다. 수달 그림은 추천 영역에서 96px(좁은 배치에서는 82px)로 사용한다. 필터는 주제 목록과 분리된 가로 필터 트레이로 표시하며, 선택 상태는 선택 토큰으로 구분한다. 필터는 실제 목록을 거르고 기존 인덱스·잠금·학습 이력·에너지 조건은 유지한다. 카드 내용은 긴 이름과 작은 화면에서도 잘리지 않게 자연스럽게 늘어난다.

## 성장·데이터 보존

성장 단계는 기존 식별자 1~5와 명칭·순서를 유지한다. 누적 XP 기준은 `0 / 20 / 100 / 300 / 800`이다. 리그 상위 1·2·3위의 금·은·동 역할도 유지한다. 시각 정리 과정에서 데이터, 재화, 보상, 에너지, 잠금, 순위, 아바타 저장값, 획득 조건은 변경하지 않는다.

## 접근성 및 검증

텍스트 대비는 일반 글자 4.5:1 이상, 비문자 경계·진행 표시 3:1 이상을 목표로 검증한다. 색만으로 상태를 표현하지 말고 문구·아이콘·형태를 함께 쓴다. 터치 영역은 최소 44px이며 320px 화면에서 가로 넘침, 헤더 잘림, 하단 메뉴 가림을 확인한다. 키보드 초점 표시와 동작 줄이기 설정을 유지한다.

## 주요 코드 위치

- `src/index.css`: 공통 스타일·그림자 제거 및 화면 공통 규칙
- `src/lib/otter.ts`: 수달 자산 연결

- `src/pages/CourseScreen.tsx`: 코스 홈·필터·주제 카드

## 공식 루빗 앱 화면을 참고한 배색 조정

사용자가 제공한 https://www.roubit.me/ko 의 미션·루틴·일기 앱 화면과 첨부 이미지를 참고했다. 홍보 이미지 바깥의 장식 배경은 앱 바탕색으로 쓰지 않는다. 연회색 바탕·흰 카드·옅은 회색 보조 버튼, 민트 선택/활성 표시와 주황 보상, 파랑·분홍·라벤더·크림·민트 원형 사물 아이콘을 조합한다. 위 색상 코드는 머니터미에 맞춰 대비를 조정한 구현값이며 루빗의 공식 색상 코드라고 주장하지 않는다. 다크 모드는 같은 역할에 맞춘 독자적인 중성 어두운 표면이다. 주요 행동은 흰 글자의 대비를 위해 차콜 채움을 유지하고, 보조 soft 버튼은 회색 바탕에 짙은 중성 글자를 쓴다.

## 리그 상위권 색상

상위1~3위의 넓은 노랑/살구색 행 배경은 사용하지 않고 일반 카드와 같은 흰 표면(다크는 같은 어두운 카드 표면)으로 통일한다. 금·은·동 역할은 작은 순위 숫자 표식에만 옅은 톤으로 남긴다. 숫자는 공통 중성 글자를 사용하고 자기 순위의 민트 강조·실제 순위/경험치·정렬은 유지한다.

리그 상위권 표시는 이후 사용자 요청으로 색 박스 대신 무채색 왕관(1위)·월계관(2위)·리본 메달(3위) 형태로 변경했다. 실제 순위 숫자는 모양 안에 유지하고 장식 그림은 접근성 읽기에서 제외한다. 행 배경은 같은 카드 표면, 자기 순위의 민트 강조와 정렬·경험치는 그대로다.

상위 순위 그림은 최종적으로 다른 사물 아이콘23종과 같은 연한 원형 바탕·윤곽선 없는 파스텔 면 그림으로 통일한다. 1위 크림/노랑 왕관, 2위 민트 월계관, 3위 라벤더/분홍 리본 메달이다. 원형 배경 반경은100좌표계의48, 작은 2면 톤만 사용한다. 숫자는 밝은 속면에 중성 짙은 글자로 표시해 다크에서도 흰색으로 바뀌지 않도록 한다. 실제 순위·경험치·자기 행 강조·캐릭터는 유지한다.

17번 복습 완료는 전용 ReviewCompletionScreen으로 분리한다. 기존 수달과 연회색 바탕을 유지하면서 오늘의 복습 표제·완료 제목·흰색 두 칸 결과 카드·현재 보유 조개 카드·고정 하단 행동으로 재구성한다. 첫 시도 정답과 최초 문제 수는 실제 값을 별도로 표시한다. 보유 조개는 획득 보상으로 표현하지 않는다. 칭찬 분기·복습 재출제·서버 제출·알림·출석 안내는 그대로 유지한다. 버튼은 기존 /course 목적지에 맞춰 학습 홈으로 표기한다. 퀴즈·다른 완료 화면에는 적용하지 않는다.

마이페이지 상단 프로필은 흰 카드 안에 기존 수달·닉네임·현재 등급을 배치하고, 그림에 겹친 편집 표식을 제거한다. 캐릭터 변경과 닉네임 변경을 이름 있는 별도 버튼으로 구분하며 기존 선택·저장 동작에 연결한다. 성장 막대는 현재 등급의 시작 경험치부터 다음 등급 기준까지의 구간을 표시한다(예:120XP는 탐험수달100~300구간의20/200XP). 최고 단계에서는 존재하지 않는 다음 목표나 진행 막대를 만들지 않는다. 등급 기준·누적 경험치·아바타 값·닉네임 저장은 바꾸지 않는다.

닉네임 변경 시트는 원형 파스텔 프로필 그림과 제목, 짧은 용도 안내, 바깥 라벨·글자 수, 단일 둥근 입력 영역, 공통 저장 버튼 순서로 정리한다. 입력 영역의 중복 카드 테두리를 제거하고 초점은 하나의 녹색 선으로 표시한다. 최대10자·현재 이름·오류 연결·지우기·필수 설정을 유지한다. 저장 버튼이 비활성인 값은 엔터로도 보내지 않고, 한글 조합 중 엔터는 확정에만 쓴다. 서버 저장 함수와 이름 검증 조건 자체는 바꾸지 않는다.

닉네임 입력 초점은 이후 요청에 따라 민트/녹색 대신 공통 중성 회색(ink-3)을 사용한다. 다크 모드에서는 같은 역할의 밝은 회색으로 전환하며, 오류 상태의 빨간 테두리는 유지한다.

27번 에너지 상점은 잔량 요약·한 줄 보유 조개·광고/조개 충전 카드·별도 부스트 구역·이용 안내로 분리한다. 비활성 옵션은 어두운 덩어리 버튼 대신 밝은 표면과 읽을 수 있는 가격·비활성 이유를 사용한다. 광고+5, 완충600조개, 부스트300조개/30분 및 기존 활성/광고 준비/잔액 부족/가득 참/처리 중 조건과 서버 콜백을 유지한다. 상위 TopBar의 구매·광고 처리와 중복 방지 로직은 바꾸지 않는다.

에너지 물고기는 기존 초록 타원·뾰족한 꼬리·아가미 선 대신 통통한 하늘색 몸통·둥근 두 갈래 꼬리·작은 분홍 볼·웃는 입으로 다듬었다. 23종 공통 규격인 반경48의 원형 바탕, 단색 면·256픽셀 투명 지원 그림·도형 원본을 유지한다. 기존 items/fish.png 연결과 에너지 수치·재화 단위는 그대로이며 다른 사물 그림과 수달 캐릭터는 수정하지 않는다.

사용자 선택에 따라 에너지 표시는 물고기 대신 둥근 금색 번개로 변경한다. 다른 아이콘과 같은 연한 라벤더 원형 바탕·단순한 두 면 색을 사용하며 얼굴 표정은 없다. 과거 fish 키·파일명은 기존 연결을 보존하기 위한 호환 경로로 남긴다. 상점·사용법의 사용자 안내는 번개로 변경하며 에너지·가격·보상·수달은 유지한다.
