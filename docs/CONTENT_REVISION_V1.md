# 뜻·퀴즈 내용 교정 v1

상태: **운영 DB 반영·재조회 검증 완료.** 검증 시각은 `content-revision-v1-verification.json`에 기록했다.

## 범위

운영 공개 콘텐츠를 읽어 1,233개 용어와 저장된 퀴즈 401개를 검토했다. 수정 대상은 119개 용어이며 필드별 건수는 서로 겹친다.

- 핵심 뜻 91개, 상세 뜻 22개
- 학습용 가상 예시 83개, 빈칸 문제용 예문 1개
- 기존 저장 퀴즈 52개

기회비용의 최선 대안, 보완재의 과도한 필수조건, 잠재성장률의 지속가능성 조건, 국민소득의 거주자 기준, 지표 단위·산식, 계산과 해설의 불일치 등을 교정한다. 확정 전 두 묶음으로 독립 교차 검증하고 정의 표현·선물과 옵션 구별·예금승수 조건·한시적근로자 분류·사중손실 문항을 추가 보완했다.

## 보존 조건

단어 식별자·단어명·힌트·출처·코스와 연결·학습 진도·지갑·재화·보상 조건은 변경하지 않는다. 기존 문제 수, 보기 수, 시각자료 위치, 레슨 체크 메타데이터도 유지한다. 퀴즈가 아닌 도표·설명 카드는 덮어쓰지 않는다.

적용은 `public.words`의 `meaning`, `detailed_meaning`, `learning_example`, `news_example`, `visuals`만 대상으로 한다. 각 대상의 다섯 콘텐츠 필드를 검토 시점과 대조하며, 원본이 달라졌으면 전체 트랜잭션을 취소한다. 이미 같은 수정안이 적용된 행은 건너뛴다. 되돌리기 역시 적용 후 예상 내용과 일치할 때만 실행된다.

## 자료와 실행

- `supabase/content/meaning-quiz-revision-v1.json`: 변경 전후 값·이유·검토 근거·보류 사항
- `supabase/content/apply-meaning-quiz-revision-v1.sql`: 전체 일괄 적용
- `supabase/content/rollback-meaning-quiz-revision-v1.sql`: 해당 변경만 원복
- `src/lib/contentRevision.test.ts`: 허용 필드·백업·메타데이터·정답·서버 제출 형식 검사

20행씩 다섯 묶음과 마지막 19행, 총 여섯 묶음으로 반영했다. 운영 공개 재조회에서 변경 대상 119/119개가 예상값과 일치했고, 비대상 1,114개 용어와 코스·연결 원문이 유지됐음을 확인했다. 단어 1,233개, 저장 문항 401개, 코스 78개, 연결 1,234행을 유지하는 범위다.

## 검증 한계

한국은행·KDI·국가통계·관계기관 자료와 기존 상세 뜻을 중심으로 변경 주장을 대조했다. 계산 예시는 별도 검산했다. 이는 전체 원문의 모든 법규·현행 한도·통계 기준에 대한 전문가 전수 감수 보증이 아니다. 추가 공식 근거가 필요한 항목은 검토 기록의 보류 목록에 남겼으며, 수정하지 않은 기존 문장까지 정확하다고 새로 인증하지 않는다. 신규 주장의 근거가 기존 원문·모형 수식인지 외부 자료인지 구별해 기록했다.
