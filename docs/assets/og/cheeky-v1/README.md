# 머니터미 공유 이미지

퀴즈·연속 출석·퀘스트·리그 승급·배지용 PNG 5종. 사용자가 제공한 원본을 기준으로 수달과 갈색·크림색을 유지하고 새 문구로 제작했다.

공유 문구 분기는 `src/lib/shareCopy.ts`, 이미지 연결은 `src/lib/share.ts`에 있다. 이미지에는 개인 점수·일수·XP·등급 번호를 고정하지 않으며 실제 기록은 공유 메시지에서 전달한다. 연속 출석 이미지의 부제는 정적 이미지용으로 “나는 벌써 출석했어. 네 내일은 언제 와?”를 사용한다.

이미지는 내장 이미지 생성 도구로 제작했다. 프롬프트는 `prompts.json`에 보관한다. `main`에 이미지가 반영된 뒤 새 앱 번들을 배포해야 공유 미리보기 URL이 공개된다.
