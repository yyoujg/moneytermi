# 화면 전체 검토 후 수정

## 변경 범위

- 학습 홈·주제 상세에 현재 에너지와 충전 방법 진입을 추가했다. 앱 이름이나 자체 뒤로가기 헤더는 추가하지 않았다.
- 마이페이지 조개 통계를 기본 상점으로 연결하고 ‘상점’ 표시와 접근성 이름을 제공했다. 열기만으로 조개·에너지를 소비하지 않는다.
- 긴 통계 값은 전체 열에 배치하고 숫자 내부 줄바꿈을 금지했다. 반올림·축약 없이 저장된 값 그대로 표시한다.
- 사용법의 복습 경로를 ‘퀘스트의 오늘 다시 볼 용어’로 맞추고 복습 대상이 있을 때만 카드가 나타나는 조건을 안내했다.
- 전역 알림은 본문 직속 포털로 표시하고 배경을 잠근다. 초기 초점·양방향 탭 순환·큐 유지·종료 후 초점 및 배경 복구를 처리했다. 기존 확인·바깥 클릭 닫기는 유지하고 Escape는 큐 한 건만 닫는다.

## 중첩 팝업 확인

실제 브라우저의 TDS 상점 위에서 알림을 띄웠을 때 기존 시트의 focusout 처리가 초기 초점을 가져가는 경합을 발견했다. 알림의 focusout 캡처 보호와 배경 잠금 이후 초점 이동, 마이크로태스크·다음 프레임 확인 및 종료 시 예약 취소로 보완했다.

모의 데이터 브라우저에서 다음을 확인했다.

- 320픽셀 홈에서 에너지 25/25 표시와 충전 안내 진입.
- 마이페이지 조개에서 기본 상점 진입.
- 320픽셀에서 1,234,567 및 2,147,483,647의 숫자 묶음 한 줄 표시. 숫자 폭은 각각 약 121/174픽셀로 가용 폭 238픽셀 안에 들어온다.
- 상점 위 오류 알림의 초기 초점, Tab/Shift+Tab 순환, 배경 접근 차단.
- Escape 후 상점 유지 및 광고 버튼으로 초점 복귀, 상점까지 닫은 뒤 배경 잠금 해제.
- 어두운 화면의 알림 및 복습 안내 문구.

운영 계정·DB·재화에 연결하지 않는 모의 응답을 사용했다. 실제 아이폰 토스 앱의 키보드·네이티브 안전영역·보조기기 검증과 구분한다.

## 보존 사항

수달·아바타 저장값, 학습 기록, 코스 연결, 답안 저장 프로토콜, 에너지·조개·경험치·미션·광고 보상 조건과 서버 SQL은 변경하지 않았다.

## 배포 구분

콘솔에서 이전 20261019-172가 출시된 것을 확인했다. 이 변경분의 실제 사용자 도달 시점은 다음 번들 검수·출시 확인과 구분한다. 기존 검수를 임의 취소하거나 기존 출시본을 롤백하지 않는다.

## 중첩 레이어·포인터 검증

TDS 시트는 10000, 일부 알림은 30000 레이어와 본문 포인터 잠금을 사용한다. 전역 알림을 40000 레이어로 두고 자체 포인터 입력을 명시해 시트 뒤에 가려지거나 확인 버튼이 클릭되지 않는 문제를 막았다. 실제 브라우저에서 확인 버튼 중심의 클릭 대상이 알림 버튼임을 확인하고, 마우스로 닫은 뒤 상점·초점이 유지되는 것과 상점 종료 후 잠금·포인터 복구를 확인했다.

검사 구성은 전체 68개 파일 630개이며, 알림 회귀 25개와 화면 동선·숫자·안내 회귀를 포함한다. 배포 조건인 전체 단위 검사·정적 검사·타입 검사·빌드는 최종 커밋에서도 다시 확인한다.
