# 학습 콘텐츠 반말 전환

운영 프로젝트 `idrdlfoouhnksielnqca`의 `words` 1,233행에 적용했다. 적용 직후 전체 행을 수정본과 비교한 결과 1,233행이 일치했고 불일치는 없었다.

- 변경: 뜻 4개, 상세 뜻 769개, 생활 예시 1,233개, 시각 자료 530개.
- 보존: 용어명, 출처, 관련 용어, ID, 난이도, 모든 숫자, 보기 순서, 정답 인덱스.
- `수요`, `총수요`, `필요`, `주요` 같은 명사의 `요`는 보존했다.
- 코스 설명과 미션 제목에는 해요체가 없어 변경하지 않았다.
- 앱의 `src/content/content.json`도 같은 수정본으로 동기화했다. 앱 화면에는 새 번들을 배포한 뒤 반영된다.

`*-before.json`은 적용 전 원본이다. `python supabase/content/casual-tone-20261118/build_revision.py`로 수정본과 `apply-01.sql`~`apply-13.sql`, `rollback-01.sql`~`rollback-13.sql`을 재생성할 수 있다. SQL은 예상 원본과 현재 행 전체가 일치할 때만 수정하고, 다른 편집이 있으면 해당 배치를 중단한다. 롤백도 동일하게 수정 이후 내용을 비교하므로 후속 편집을 덮어쓰지 않는다.

현재 앱이 사용하지 않는 레거시 테이블과 사용자 학습 기록은 이 변경에 포함하지 않는다.
